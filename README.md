# AstrBot_siwu-arknights-query

明日方舟（Arknights）游戏数据查询插件，适用于 [AstrBot](https://github.com/Soulter/AstrBot)。由 Amiya-Bot 的同名查询插件移植而来，复用其 HTML 模板与数据源，通过 Playwright 无头浏览器截图出图。

支持 **Agent 主动调用**：在对话中让 AI 助手（Agent）自主判断并调用工具。工具统一遵循「数据回传 LLM」模式——文字结果返回给 LLM 组织语言回复；资料图片由工具自动直发用户（LLM 无法展示图片），同时返回简短摘要供 LLM 收尾。

## 功能

- **干员查询**：星级/职业/天赋/技能/属性/档案（详情页）、精英化与专精材料、技能详情（全部等级与专精数据）、召唤物信息、模组（解锁条件/任务/属性/效果/升级材料）、皮肤（立绘/系列/画师/获取途径/台词）
- **材料查询**：材料简介、合成公式（合成树）、可获取关卡与掉落概率、一图流推荐价值
- **敌方单位查询**：属性（血量/攻击/防御/法抗/移动速度等）、能力词条、关联单位
- **关卡查询**：关卡地图/敌方单位/掉落详情（支持关卡代号、关卡名、活动名、难度词如「突袭」「磨难」），同名多关卡让用户选序号，活动关卡列表、活动列表、生息演算地图
- **术语查询**：游戏术语/地形说明（如「晕眩」「束缚」「草丛」「高台」）
- **公招查询**：根据标签/文字推荐公开招募组合图（支持「高资」「资深」等口语、视觉模型识别公招界面截图全部标签；推荐组合图直发、推荐语由 LLM 组织）
- **代号记录**：支持登记干员/敌方单位的社区外号（如「夏游洁」→「予愿安洁莉娜」），查询时自动用代号记录解析用户输入，Agent 可自助登记/更新/删除

数据自动从 gitee 拉取（`amiya-bot-assets`）并解析到内存，无需手动更新。

## 安装

1. 在 AstrBot 管理面板 → 插件管理 → 安装插件 → 上传 zip（本仓库 Release 中的 `siwu-arknights-query-<version>.zip`）
2. 插件依赖 `playwright`，需在 AstrBot 环境安装 Chromium 浏览器内核：

   ```bash
   # 在 AstrBot 的 Python 环境执行（Windows 示例）
   python -m playwright install chromium
   ```

   > 依赖已固定为 `playwright==1.53.0`，与该内核版本匹配，请勿随意升级。

3. 插件激活后会自动在后台从 gitee 拉取游戏数据（首次拉取需要几分钟），完成后即可查询。

## 使用

### Agent 主动调用（推荐）

安装后，在支持 Agent 的 AstrBot 对话中直接提问，AI 会自动调用工具并发送图片：

- 「查一下干员 银灰」
- 「棘刺的专精材料要什么」
- 「W 的技能详情」
- 「银灰有召唤物吗」
- 「银灰的模组」（模组资料卡：解锁条件/任务/三级属性/效果/升级材料）
- 「看看 W 的皮肤」（最新皮肤立绘卡；回复中会列出全部皮肤，可继续指定第几张）
- 「提纯源岩哪里刷」
- 「爱国者这个敌人的数据」
- 「查一下夏游洁」（若「夏游洁」是已登记的代号，会命中「予愿安洁莉娜」）
- 「1-7 怎么打」「CE-6 掉落」「SV-3 突袭」（关卡查询，自动发送关卡图片）
- 「骑兵与猎人的关卡」（活动关卡列表）
- 「晕眩是什么意思」「草丛地形」（术语/地形说明）
- 「帮我查公招」「公招 高资 群攻」或直接发送公招界面截图（自动用视觉模型识别图中全部标签并推荐组合）

查询流程中的代号处理：

1. 查询工具按 **真名精确匹配 → 英文名 → 代号表 →（可选）模糊匹配** 的顺序解析名称；真名永远优先，代号表不会遮蔽同名干员
2. 未命中且本地无此名时，工具会引导 Agent **自行调用 AstrBot 的联网搜索工具**（`web_search_tavily`）确认该代号对应的官方名称
3. Agent 确认后调用代号管理工具**登记**（`夏游洁 → 予愿安洁莉娜`），记录会立刻写进**插件配置**（`akq_alias_operator` / `akq_alias_enemy`，面板上可见可改），后续查询直接命中；登记/修改都做精确校验——规范名必须与游戏内名称完全一致（不做模糊匹配，查不到直接拒绝），代号本身若已是现有规范名也会被拒绝（那只会遮蔽真名）
4. **用户纠正即修表**：当用户指出查询对象不对（「我问的是克莱门莎，不是莎草」），Agent 会自己用 `query` 找到那条错记录，判断是 `update` 改成正确映射还是 `remove` 删掉（错记录会继续污染之后所有查询），然后重新查询出图——用户不需要说「删除/修改」
5. 代号表是插件配置项，用户也可以直接在面板上增删改；改完插件重载即生效（AI 改动是即时写入的，面板刷新就能看到）

### 子代理提示词配置（可选，推荐）

若你的 AstrBot 使用子代理编排（SubAgent Orchestrator）且存在 `subagent_arknights` 子代理，其 persona 提示词建议补充「名称原样传参」规则，避免子代理把用户原话中的谐音/社区称呼（如「芋圆安洁莉娜」→ 安洁莉娜）改写后查询错对象：

```
你是明日方舟数据查询助手。用户需要查询干员、材料、敌人、关卡、术语或公招推荐时，调用分配给你的工具执行，返回查询结果即可。

注意事项：
1. 【名称原样传参】用户消息中出现的干员/敌人/材料/关卡名称必须原样传给工具参数，禁止改写、翻译或拆解成其他名称；社区谐音称呼（如「芋圆安洁莉娜」「夏游洁」「银老板」「二哥」）也必须原样传入——工具内置代号表会自动解析为官方名称（如「芋圆安洁莉娜」→「予愿安洁莉娜」）。若工具返回"未找到"引导，按引导执行，不要自行改名重查。
2. arknights_query_operator 的 query_type 一律使用英文取值：info/cost/skills/tokens/module/skin，不要用中文（如"皮肤"应传 skin，"模组"应传 module）。
3. 查询图片由工具直接发送给用户，你只需简短汇报查询对象与结果即可。
```

> 该配置位于 AstrBot 管理面板「子代理/人格」或数据表 `personas` 的 `system_prompt` 字段，属于运行环境配置而非插件代码；插件本身不做任何与子代理编排耦合的改动，保证可移植性。


### 命令回退（需 @ 机器人或唤醒词）

- `查干员 xxx` — 干员详情
- `查材料 xxx` — 材料资料
- `查敌人 xxx` — 敌方单位资料
- `查关卡 xxx` — 关卡资料（关卡代号/名称/活动/生息演算地图）
- `查术语 xxx` — 术语/地形说明
- `查公招 [标签]` — 公开招募推荐（支持文字标签，发送公招界面截图时自动用视觉模型识别全部标签）

## 配置

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| `akq_enabled` | 启用明日方舟查询（关闭后工具与命令不再响应） | `true` |
| `akq_auto_update` | 启动时自动拉取/更新游戏数据（关闭则使用本地已有数据） | `true` |
| `akq_repo_url` | 游戏数据仓库地址（Amiya-Bot 官方数据源，一般无需修改） | `https://gitee.com/amiya-bot/amiya-bot-assets.git` |
| `akq_auto_fetch_material_value` | 自动拉取材料价值数据（一图流 yituliu.cn） | `true` |
| `akq_render_width` | 渲染图片宽度（px）。HTML 模板为 1280px 固定画布，无需修改 | `1280` |
| `akq_render_timeout` | 渲染超时时间（秒） | `30` |
| `akq_vision_enabled` | 公招截图标签识别（视觉模型）：开启后发送公招截图自动识别图中全部标签并与文字转述合并，防止只计算其中几个标签 | `true` |
| `akq_vision_provider_id` | 视觉模型 Provider ID（如 `siliconflow/Qwen/Qwen3-VL-32B-Instruct`）。留空则自动使用全局「图片描述」Provider（`provider_ltm_settings.image_caption_provider_id`），再留空则用当前默认 Provider | 空 |
| `akq_alias_operator` | **干员代号（黑话）表**：每行一条「代号=规范名」，规范名必须是游戏内完整名称。查询时自动把代号解析成规范名；AI 查询出错（你纠正它「我问的是克莱门莎，不是莎草」）时会自己回来改这张表，你也可以在这里直接增删改 | 内置常用外号（`42姐=史尔特尔`、`夏游洁=予愿安洁莉娜` 等，见插件面板） |
| `akq_alias_enemy` | **敌方单位代号表**：格式同上，如 `大爹=爱国者` | 内置 `大爹=爱国者` |

## 数据来源

- 游戏数据：<https://gitee.com/amiya-bot/amiya-bot-assets>（Amiya-Bot 官方数据仓库，随游戏版本自动更新）
- 材料价值：一图流 <https://yituliu.cn>

## 移植注意

- **Chromium 内核**：本机若缺少匹配的 Playwright 浏览器内核会渲染失败，必须执行 `python -m playwright install chromium`
- **git 依赖**：首次安装（无本地数据时）需通过 `git clone` 拉取数据源，机器需可用 git；已有数据时失败会回退本地缓存
- 渲染出图需要本机能访问本地文件与正常启动 Chromium（无头模式）
