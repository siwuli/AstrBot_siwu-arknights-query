# 明日方舟查询（arknights_query）

明日方舟游戏数据查询插件，由 Amiya-Bot 同名插件移植，复用其 HTML 模板与数据源，用 Playwright 无头浏览器截图出图。文字结果回传 LLM 组织回复，资料图片由工具直发用户。

## 功能

- **干员**：星级/职业/属性/天赋/档案、精英化与专精材料、技能详情、召唤物、模组、皮肤
- **材料**：简介、合成公式、可获取关卡与掉落概率、一图流推荐价值
- **敌方单位**：属性、能力词条、关联单位
- **关卡**：地图/敌人/掉落，支持关卡代号、关卡名、活动名与「突袭」「磨难」等难度词
- **术语**：游戏术语与地形说明（如「晕眩」「草丛」「高台」）
- **公招**：按标签推荐可锁定稀有干员的组合，支持口语标签与公招界面截图识别；图里只画锁得住稀有干员的组合
- **代号**：登记干员/敌方单位的社区外号（如「夏游洁」→「予愿安洁莉娜」），查询时自动解析，Agent 可自助增删改
- 数据从 gitee 自动拉取并解析到内存，无需手动更新

## 使用

### Agent 主动调用（推荐）

安装后直接在对话里提问，AI 会自动调用工具并发送图片：

- 「查一下干员 银灰」「棘刺的专精材料要什么」「W 的技能详情」「银灰的模组」「看看 W 的皮肤」「银灰有召唤物吗」
- 「提纯源岩哪里刷」「爱国者这个敌人的数据」「晕眩是什么意思」「草丛地形」
- 「1-7 怎么打」「CE-6 掉落」「SV-3 突袭」「骑兵与猎人的关卡」
- 「帮我查公招」「公招 高资 群攻」，或直接发送公招界面截图（自动识别图中全部标签）

- 名称解析顺序：真名精确匹配 → 英文名 → 代号表；未命中时引导 Agent 联网确认官方名称后登记代号，用户纠正查询对象时 Agent 自行改表
- 使用子代理编排时，其 persona 需约定「名称原样传参」，避免谐音外号被改写后查错对象

### 命令回退（需 @ 机器人或唤醒词）

- `查干员 xxx` — 干员详情
- `查材料 xxx` — 材料资料
- `查敌人 xxx` — 敌方单位资料
- `查关卡 xxx` — 关卡资料
- `查术语 xxx` — 术语/地形说明
- `查公招 [标签]` — 公开招募推荐

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `akq_enabled` | `true` | 启用查询（关闭后工具与命令不再响应） |
| `akq_auto_update` | `true` | 启动时自动拉取/更新游戏数据 |
| `akq_repo_url` | gitee 数据源 | 游戏数据仓库地址，一般无需修改 |
| `akq_auto_fetch_material_value` | `true` | 拉取材料价值数据（一图流） |
| `akq_render_width` | `1280` | 渲染宽度（模板固定 1280 画布，无需修改） |
| `akq_render_timeout` | `30` | 渲染超时时间（秒） |
| `akq_vision_enabled` | `true` | 公招截图标签识别（视觉模型） |
| `akq_vision_provider_id` | 空 | 视觉模型 Provider ID；留空复用全局图片描述 Provider |
| `akq_alias_operator` | 内置常用外号 | 干员代号表，每行 `代号=规范名` |
| `akq_alias_enemy` | `大爹=爱国者` | 敌方单位代号表，格式同上 |

## 安装

1. 管理面板 → 插件管理 → 安装插件 → 上传 `siwu-arknights-query-<version>.zip`
2. AstrBot 的 Python 环境执行 `python -m playwright install chromium`（依赖固定 `playwright==1.53.0`，请勿升级）
3. 激活后自动在后台拉取游戏数据，首次需几分钟；机器需可用 git，渲染需能启动 Chromium
